# How to publish a blog post (from your phone)

1. Open github.com/AInturi18/akhilinturi.com/new/main/_posts
2. File name: `YYYY-MM-DD-short-title.md` (example: `2026-10-15-passed-ansi-cert.md`)
3. Paste this at the top, then write below it:

```
---
layout: post
title: "Your post title"
category: Updates
description: One sentence that shows on the blog list.
---

Write your post here. Use ## for headings, **bold**, - for bullets.
```

4. Tap **Commit changes**. It's live at akhilinturi.com/blog/ in about a minute.

**Categories:** Data Center · Networking · Projects · Career · Updates · Life (or make up a new one; it shows as a filter automatically)

**Add an image:** upload it to the repo, then write `![description](/image-name.jpg)` in the post.

**Fix a post:** open it in `_posts`, tap the pencil, edit, commit.
**Delete a post:** open it, ⋯ → Delete file.
